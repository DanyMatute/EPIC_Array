# EPIC Array Walkthrough
ACTIVE DEVELOPMENT!!!

A comprehensive R workflow for analyzing Illumina EPIC (Epigenetic Chemical) methylation array data from start to finish.

## Overview

This repository provides a complete pipeline for DNA methylation analysis using Illumina EPIC v2.0 arrays. It includes detailed code and explanations for processing raw methylation data, performing quality control, and conducting statistical analysis to identify differentially methylated positions and regions.

### Main Workflow

The analysis follows these seven key steps:

1. **Raw Data Import** - Loading .idat files containing fluorescent intensities from both red and green channels
2. **Quality Control** - Assessing sample and probe quality using detection p-values and signal distributions
3. **Preprocessing** - Background correction, normalization to account for probe type differences, and probe filtering
4. **Methylation Quantification** - Converting red/green signal ratios to beta-values and M-values
5. **Batch Effect Correction** - Removing technical variation while preserving biological signals
6. **Statistical Analysis** - Identifying differentially methylated positions (DMPs) and regions (DMRs)
7. **Biological Interpretation** - Annotating results and performing pathway enrichment analysis

## Key Analysis Components

### Raw Data Import

Reads paired .idat files (red and green channels) and extracts sample metadata from filenames. Supports batch processing of multiple samples.

### Quality Control

- **Detection p-values** - Assess whether probe signal exceeds background
- **Sample filtering** - Remove samples with >5% failed probes
- **Probe filtering** - Remove probes that fail in >10% of samples
- **Visualization** - PDF plots of sample quality metrics

### Preprocessing

- **Functional normalization** - Correct for technical variation (preprocessFunnorm)
- **Beta-value extraction** - Represents proportion of methylation (0-1)
- **M-value extraction** - Log2 ratio, better for statistical testing

### Probe Filtering

Removes problematic probes including:
- Cross-reactive probes (may bind multiple locations)
- SNP-affected probes (genetic variants impact binding)
- Sex chromosome probes (avoid sex-related confounding)
- Incomplete data across samples

### Outlier Detection

- Principal Component Analysis (PCA) to identify sample relationships
- Mahalanobis distance for statistical outlier detection
- Sample correlation heatmaps for visual inspection

### Differential Methylation Analysis

**DMRcate approach:**
- Tests for differentially methylated positions (DMPs) using limma
- Identifies differentially methylated regions (DMRs) using spatial correlation
- Accounts for multiple testing correction (FDR < 0.05)

### Enrichment Analysis

- **Gene Ontology (GO)** - Biological processes, molecular functions, cellular components
- **KEGG pathways** - Metabolic and signaling pathway analysis

## Data Types Explained

### Beta-values (β)
- Ratio of methylated to total signal (0-1 scale)
- Intuitive interpretation: 0 = unmethylated, 1 = fully methylated, 0.5 = 50% methylated
- Useful for visualization and interpretation

### M-values
- Log2 ratio of methylated to unmethylated signal
- Better statistical properties than beta-values
- Recommended for statistical testing and differential analysis

## Checkpoints

The analysis includes intermediate checkpoints that save processed data:

1. `01_raw_import.rds` - Raw data after reading .idat files
2. `02_qc.rds` - After quality control filtering
3. `03_normalized.rds` - After normalization
4. `04_filtered_methylation.rds` - After probe filtering and outlier detection
5. `05_differential_methylation.rds` - After differential analysis

These allow you to resume analysis at different stages without re-running earlier steps.

## Tips for Your Analysis

- **File naming convention** - Embed sample type and treatment information in filenames for automatic parsing
- **Memory usage** - Methylation arrays are memory-intensive; consider processing samples in batches for very large studies
- **Quality control** - Always inspect QC plots before proceeding to downstream analysis
- **Multiple testing correction** - Default FDR threshold is 0.05; adjust based on your study design
- **Batch effects** - Use ComBat correction if samples were processed in different batches
